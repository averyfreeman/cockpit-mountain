What this number does not include

A coverage figure that quietly omits part of the shipped logic is worse than no figure, so the omissions are named here.

  • libexec/hangar-run — about 2200 lines of Python. It is driven end to end by tests/integration against a real restic and stub binaries, and node cannot instrument it. Its behaviour is tested; it is simply not counted above.
  • index.html, css/, html/ — markup and styles, with no executable logic to cover.
  • tests/ — a test file’s own coverage says nothing about the code under test.

The figures come from tests/unit alone. The integration, smoke, e2e and real-Cockpit suites all execute this same source and would raise every number here; none of them are counted.

Per-line detail lives in coverage/lcov.info, which is regenerated on demand and not committed. GitHub shows this file as source rather than rendering it — open it from a checkout.
