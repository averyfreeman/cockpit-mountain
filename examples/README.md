# Runnable examples

Each example gets one directory with its source, package manifest when it uses
Node, and a README with prerequisites and copyable run commands. Keep examples
small enough to demonstrate one Cockpit pattern. Do not commit build output,
package archives, local dependencies, or screenshots generated by a test run.

Reusable explanations belong in
[`../forks/guidance-focused/guides/`](../forks/guidance-focused/guides/); link to
an example rather than copying the same code into a guide.

## Current examples

- [`cockpit-starter-lessons/`](cockpit-starter-lessons/): React 19 and Oxlint
  teaching fork of Cockpit Starter Kit. Its separate Git checkout is kept at
  `forks/cockpit-starter-lessons/` so the monorepo and its remote remain easy to
  work with independently.
